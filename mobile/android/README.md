# MusicFlow — Android Studio Project

Full Android Studio project for **MusicFlow Mobile** (`com.musicflow.mobile`).

### Opening in Android Studio
1. Open Android Studio.
2. Select **File > Open** and choose this folder:
   ```
   musiccc\mobile\android
   ```
3. Allow Gradle to sync.
4. Click **Run ▶** to deploy directly to your phone or emulator!

### Command-Line Build
```bat
build.bat debug
build.bat release
```

For full details on connecting to your PC's localhost, see [BUILD_APPS.md](../../BUILD_APPS.md).
